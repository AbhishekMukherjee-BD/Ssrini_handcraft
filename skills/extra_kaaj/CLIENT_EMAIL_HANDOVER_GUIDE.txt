--------------------------------------------------------------------------------
The website uses PHPMailer to send real-time, automated transactional emails
(Order Confirmations, Payment Receipts, Shipping Tracking Updates) directly
via Google Mail's secure SMTP server (smtp.gmail.com over TLS on port 587).

All configuration is strictly decoupled from the code and managed inside
the environment configuration file: .env

4. CLIENT HANDOVER INSTRUCTIONS: WHAT THE CLIENT NEEDS TO DO
--------------------------------------------------------------------------------
To enable live emails from the client's official Gmail or Google Workspace
account, provide these exact instructions to the client:

STEP 1: Log in to the Google Account
   Log in to the Gmail or Google Workspace account that should send the emails
   (e.g., contact@ssrini.com or amitguddu2505@gmail.com).

STEP 2: Enable 2-Step Verification
   - Go to: https://myaccount.google.com/security
   - Under "How you sign in to Google", ensure "2-Step Verification" is turned ON.

STEP 3: Generate a Google "App Password"
   - Go directly to: https://myaccount.google.com/apppasswords
     (Or search "App Passwords" in the Google Account search bar).
   - Enter an App Name: e.g., "SSRINI Store"
   - Click "Create".
   - Google will display a unique 16-character password (e.g., abcd efgh ijkl mnop).
   - Copy this 16-character password immediately.

STEP 4: Update the .env File
   Open the .env file on the server and fill in:
   
   SMTP_USER=your-actual-email@gmail.com
   SMTP_PASS=abcdefghijklmnop

   (Note: Spaces in the 16-character password can be kept or removed).

STEP 5: Save the file
   Once saved, emails are immediately live! No server restart required.

6. SECURITY NOTES FOR HANDOVER
--------------------------------------------------------------------------------
- Never commit the real .env file with live passwords to public Git repositories.
- The root .htaccess has been hardened to block any web browser from downloading

- An App Password is safe because it does NOT give access to your Google account

  at any time.
